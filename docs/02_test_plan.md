# แผนการทดสอบรับงาน (T1–T7)

> ผลทุกข้อต้องมีข้อมูลดิบ ค่าเฉลี่ย และค่าคลาดเคลื่อนสูงสุดในรายงาน
> เก็บข้อมูลดิบ (CSV/ตาราง) ไว้ในโฟลเดอร์ `/data` ของ repo นี้

| # | การทดสอบ | ข้อกำหนด | วิธีทดสอบ | ข้อมูลที่ต้องบันทึก | เกณฑ์ผ่าน | ผล |
|---|---|---|---|---|---|---|
| T1 | ความซ้ำได้ของ homing | R1 | home 10 ครั้ง เริ่มจากตำแหน่งต่างกัน | ค่า encoder และค่าสเกลที่ตำแหน่ง 0 ทุกครั้ง | ต่างกันไม่เกิน ±0.5 mm | |
| T2 | ความแม่นยำตำแหน่ง | R3, R5 | เป้าหมาย 5 จุด จุดละ 3 ครั้ง เข้าหาจากสองทิศ | ตำแหน่งที่สั่ง/encoder/สเกล | คลาดไม่เกิน ±0.5 mm | |
| T3 | ความแม่นยำความเร็ว | R4 | เคลื่อนที่ระยะคงที่ที่ความเร็ว 3 ค่า | เวลาและความเร็วเฉลี่ยจาก encoder | คลาดไม่เกิน 5% | |
| T4 | ขอบเขตการเคลื่อนที่ | R2 | สั่งเกิน soft limit และเคลื่อนช้า ๆ เข้าหา limit sensor | ระยะหยุดหลังเซนเซอร์ทำงาน และระยะเหลือถึงปลายแกน | ไม่ชนปลายแกน | |
| T5 | ตรวจจับสเต็ปหาย | R5 | ทำให้สเต็ปหายแบบควบคุมได้ (เช่น เร่งสูงเกินไป/ลดกระแสชั่วคราว) | ผลต่างตำแหน่งที่สั่งกับ encoder + ข้อความแจ้งเตือน | ตรวจจับได้ทุกครั้ง | |
| T6 | หยุดฉุกเฉิน | R7 | กดปุ่มขณะเคลื่อนที่ความเร็วสูงสุด และขณะ homing | เวลาและระยะจากกดปุ่มถึงหยุดสนิท | หยุดทันทีทุกสถานะ | |
| T7 | ความทนทาน | R1–R6 | เคลื่อนที่ไปกลับ 20 รอบ แล้วกลับ home | ความคลาดเคลื่อนสะสมหลัง 20 รอบ + อุณหภูมิมอเตอร์ | ตามเกณฑ์กลุ่มกำหนด | |
