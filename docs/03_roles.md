## กติกาของทีม
- ทุกคนต้องมี commit หรือเอกสารที่ตนรับผิดชอบใน repository
- ทุกคนต้องนำเสนอส่วนของตนใน Final Presentation และตอบคำถามได้
- รายงานต้องมี contribution table (ตารางนี้) และทุกคนส่งแบบประเมินเพื่อนร่วมทีมแยกกัน
